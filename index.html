    How the Windows version works

    Open HotkeyWorkbench.ahk with AutoHotkey v2. Preview is enabled by default. The live shortcuts are limited to left4dead2.exe while it is foreground. F8 pauses and Alt+F5 exits within the panel or target window. Cancellation and focus checks stop pending steps.

    Timing values are requested delays, not a guarantee of exact operating-system timing. Browser preview and native game execution are different environments.

    Original Python sequences: Q wheel down/up · T left/right click · 1 left/right click + Space. No game compatibility claim is made for the client's script.
