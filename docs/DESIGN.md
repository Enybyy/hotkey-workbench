# Hotkey Workbench

Qué es: secuencias de teclado y ratón para Windows, derivadas del script Python de L4D2.
Para quién: clientes que necesitan mantener scripts y comprobar secuencias de entrada.
Objetivo: probar una secuencia, comprender sus tiempos e instalar la versión AutoHotkey v2.

Color: petróleo #16485B texto/estructura; hielo #EAF2F5 fondo; blanco #FFFFFF superficie; amarillo #F5C542 teclas; gris #526570 secundario; azul #176786 acciones.
Tipografía: Segoe UI para controles y títulos, Consolas para tiempos y eventos.
Layout alineado a la izquierda: selector de secuencia y controles junto a línea de tiempo y registro. Las teclas físicas son el elemento memorable, sin degradados.

```text
Hotkey Workbench                        Código / Windows
Una tecla. Una secuencia visible.
Q / T / 1    | pasos, tiempos, resultado
Ejecutar    | consola
Pausar      | limpiar / exportar
```

La demo web representa acciones dentro de la página; no envía entrada al juego. El código Windows es independiente y parte en modo de vista previa. No se promete compatibilidad comprobada con el juego del cliente.
